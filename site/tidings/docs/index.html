Make yourself at home.

Set up in the browser or in a terminal.

sudo tidings setup
sudo tidings create-owner --username yourname
sudo tidings set-password --username yourname

setup prints a private key for the browser page. The account commands ask for the password twice without showing it. Scripts can use --password-stdin or --password-file PATH, and --data-dir DIRECTORY picks an instance. More in the setup guide.

Write every setting as KEY="value", following the shared configuration format. OpenRC reads /etc/conf.d/tidings; systemd reads /etc/tidings/tidings.env.

When something needs attention.

Start with the deployment guide. Still stuck? search or open an issue with your app version, how you installed it, and the error. Remove passwords, tokens, and private data from logs first.
