Self-hosted · Open source · Docker images, Linux binaries, Debian packages, and a Gentoo overlay

A table set for reading.

Your own reading list

Follow feeds, tag your sources, and group them by interest. OPML import and export let you bring your subscriptions with you.

A household table, if you want it

The host can keep shared sources. Everyone starts with the household table off and can join or leave any time. Your own subscriptions stay yours.

Your reading is yours

Read markers and saved stories belong to each person, even on shared sources. Opening a story doesn’t mark it read; you do that when you’re done.

Comfortable to read

Stories keep their formatting, with optional pictures supplied by feeds. Get full story fetches the original article when a feed sends only an excerpt. Keyboard shortcuts are there if you turn them on.

Fresh stories, no hurry.

Following a source fetches it right away. A live indicator shows progress and when the next check is due. Quiet or failing sources get checked less often. Read on, and open the new stories when you’re ready.

Owners can offer suggested sources by category. Suggestions start off and never subscribe anyone.

A copy worth keeping.

The running service makes verified backups automatically each day. Keep a protected copy on another machine too, and practice restoring it. The backup and recovery guides explain what to keep and how to recover.

Make it yours

Set the reading table.

Tidings runs as one Go binary with a SQLite database. You’ll need a server, and HTTPS for an installation you share online.

  1. Pick your installation.

    Use a published image with Docker Compose, follow the binary and Debian package guide, or use the Gentoo overlay. Want a look first? Try the local demo.

  2. Set up your place.

    The deployment guide covers your owner account, HTTPS, and running the service.

  3. Pull up a chair.

    Follow a few feeds, invite your household, and read the first page.

Inspired by Miniflux.

Tidings borrows its reading features from Miniflux and builds them around SQLite and households.
