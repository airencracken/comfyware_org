Comfylib.

The shared foundation for Imvault, Witmoot, and Songstead.

Small Go packages for the things the apps need to get right together: private backups, tokens, trusted proxies, process isolation, and familiar account and invitation forms.

Current release: Comfylib 0.1.7

Source and documentationGo package reference

One implementation, used together.

Comfylib is a Go library used by the Comfyware apps. Its Go packages use only the standard library and add no further modules to your dependency tree. Each app pins an exact published version.

  • Security tools: random tokens, session-bound CSRF tokens, trusted client addresses, private key files, transactional mail, and Bubblewrap process confinement.
  • Care for your data: bounded image normalization, member profile validation, and verified automatic backups with private archives and limited retention.
  • Shared forms: responsive account and invitation styles, invitation availability, and browser checks for both themes and keyboard access.

Applications own their palettes, templates, permissions, storage, and atomic invitation redemption. The shared library keeps common behavior and checks in one place.

Use it in a Go project.

Source builds need Go 1.26 or newer. Pin the release in your project:

go get github.com/airencracken/comfylib@v0.1.7

Choose the packages you need in the package guide. Comfylib is licensed under AGPL-3.0-or-later.

See it at home.

Comfylib supports Imvault's photo library, Witmoot's conversations, and Songstead's music recommendations. Each app has its own installation guide and runs independently.
