Make yourself at home.

Choose browser setup or a terminal prompt. The installed command finds the service’s data directory and account.

sudo folkweave setup
sudo folkweave create-owner --username yourname
sudo folkweave set-password --username yourname

setup shows the private key for the browser page. The account commands prompt twice with echo disabled. Automation can use --password-stdin or --password-file PATH; --data-dir DIRECTORY selects an instance. See the setup guide.

Service config examples follow the shared configuration format: use KEY="value" for every value. OpenRC reads /etc/conf.d/folkweave; systemd reads /etc/folkweave/folkweave.env.

When something needs attention.

Start with the deployment guide for configuration and service setup. If you are stuck, search or open an issue with your app version, installation method, and the relevant error. Remove passwords, tokens, and private community data before sharing logs.
