# Songstead mascot

`site/assets/songstead-jukebox.png` is the transparent 480 × 480 web version of
Songstead's jukebox mascot, shared with the application's embedded asset.
It is 156 KiB, below the website's 200,000-byte image budget.

The original was generated with the built-in imagegen tool. Imvault's blue
mascot supplied the main graphic style reference; Witmoot's Moot Knight supplied
the warmth reference. The original PNG and exact generation prompt are retained
in Songstead's `design/` directory. The web version was resized and losslessly
encoded for practical delivery, preserving transparency.
